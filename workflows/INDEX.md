# Workflows

Task entry. Each file is a pointer, not a procedure dump.

| Workflow | Read when |
|----------|-----------|
| `closed-loop.md` | whole-app `@orchestrator` / `yarn loop` |
| `implement.md` | feature or bugfix in `app/` or pack runtime |
| `review.md` | reviewing a diff |
| `debug.md` | unclear test/CI failure |
| `release.md` | ship, deploy, post-deploy, curator |
| `sync.md` | you edited `agents/` or `skills/` |

Pick **one**. Then open the files it names.
