# Implement

**When:** writing or fixing product or pack runtime code as the implementer (you are not orchestrating).

1. `context/profile.json` (stack + package manager for the path you touch)
2. `context/conventions.md`
3. Role: `agents/implementer.md` and at most one specialist (`frontend` / `backend` / `data` / `mobile`)
4. UI → `paths.design`. Auth/money/scores → `context/trust.md`
5. `loop/learnings.md` Standing rules only

Then `workflows/review.md` before merge. Do not open spec/architecture unless the change is a contract change.
