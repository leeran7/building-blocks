# Knowledge

Memory lives in `loop/`. This folder does not copy it.

| Need | File | How |
|------|------|-----|
| Standing rules | `loop/learnings.md` | read until `## By topic`, then stop |
| One topic | same file, that `###` heading | do not read sibling topics |
| One past event | `loop/learnings.jsonl` | Grep; never dump |
| Spec | `loop/spec.md` | product-spec / QA only |
| Architecture | `loop/architecture.md` | architect / contract mismatch |
| History | `archive/INDEX.md` | explicit historical task |

`loop/INDEX.md` is the directory map.
