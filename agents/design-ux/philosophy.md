# Design Philosophy & Process

## Core Principles

**Clarity** — one obvious primary purpose per screen; recognition over recall; progressive disclosure.

**Hierarchy** — establish through typography, scale, spacing, contrast, position, motion, color, density. The most important action must feel important.

**Simplicity** — remove anything that doesn't help the user, communicate hierarchy, reinforce the product, or earns its place. Not emptiness.

**Human-centered** — design around user goals, context, expectations, thumb reach, attention, a11y, error recovery, one-handed use, interruption, slow networks, empty states.

**Platform respect** — follow iOS/Android conventions unless there is a strong product reason not to. Understand the underlying interaction principles; don't blindly copy platform UI.

---

## Design Process

### Step 1 — Understand the Product
Identify: purpose, target users, primary problem, core journey, business objective, primary conversion, usage frequency, context, competitive alternatives, differentiating value. State assumptions explicitly when info is missing.

### Step 2 — Define Information Architecture
Determine: primary/secondary navigation, content hierarchy, screen hierarchy, user flows, entry/exit points, feature relationships. Prefer the simplest architecture that works.

### Step 3 — Map Core User Flows
Before individual screens: Entry → Orientation → Primary action → Decision points → Confirmation → Feedback → Completion → Return.

Also cover: errors, undo, cancellation, back navigation, interrupted flows, empty states, loading, offline, permissions, auth, first-time use.

---

## Mobile UX Expertise

Design for touch first. Comfortable touch targets (44×44 min), no precision required.

Patterns: iOS/Android UX, bottom/tab navigation, sheets, modals, full-screen flows, gestures (swipe, long press, pull-to-refresh, drag), search/filter, forms, onboarding, auth, checkout, payments, notifications, settings, profiles, dashboards, feeds, messaging, media, maps, commerce, SaaS, AI products.

---

## Apple-Level Visual Design

Interfaces should feel: premium, calm, intentional, modern, native, sophisticated, responsive, cohesive.

Avoid: gratuitous gradients, excessive glass effects, random rounded cards, overuse of shadows, excessive borders, tiny text, visual noise, excessive animation, decorative UI without purpose, generic AI-generated layouts.

Use whitespace deliberately. Not every element is a card. Not every element gets rounded rectangles.
