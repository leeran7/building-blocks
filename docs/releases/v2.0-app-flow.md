Before release:

- No server deploy is required for the app flow: it adds no new
  `/api/...` paths, no Prisma migrations, and no env vars. The payments
  doc (`docs/releases/v2.0-payments.md`) covers the server-side steps for
  2.0 (migrations, `DAILY_SEED_SECRET`, App Store gem products,
  `APPLE_IAP_SANDBOX_UIDS`).
- App Store submission needs: new screenshots (tab bar, map, Shop, Skin
  Details and Profile all changed since 1.2), fresh What's New copy, and
  the review demo account's Firebase uid in `APPLE_IAP_SANDBOX_UIDS`
  (see the payments doc).
- Device smoke test (not done by anyone yet): fresh install → tutorial →
  guest levels 1–3 → sign in (Apple and Google) → play a level → map climb
  animation → chest sheet → Shop sandbox gem purchase credits gems → buy a
  Void skin → lives refill → Daily opens a tower → Quick Play duel →
  challenge link opens the app.
